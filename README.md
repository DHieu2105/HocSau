
# Fruit Detection Using YOLOv5

Deep Learning project for detecting two fruit classes:
Pomelo and Peach.

## Technologies

- Python 3.12
- PyTorch
- YOLOv5
- OpenCV
- Streamlit

## Classes

- 0: pomelo
- 1: peach

## Project Structure

- configs/: Dataset configuration
- scripts/: Custom scripts
- datasets/: Local training data
- runs/: Training and inference outputs
- samples/: Example images
- docs/: Project documentation

## Model

YOLOv5s pretrained weights, fine-tuned on a custom
fruit detection dataset.

Official YOLOv5 repository:
https://github.com/ultralytics/yolov5
